# Driver Safety Guide

## Safe driver sources

Prefer these sources:

1. Windows Update
2. Your laptop or motherboard manufacturer's official support page
3. NVIDIA, AMD, Intel, Realtek, Qualcomm, or another official hardware vendor

## Avoid

- Unknown driver-updater websites
- Executables from random forums
- Driver packs from unverified sources
- Disabling Windows security to install a driver

## Before replacing a driver

- Create a restore point when appropriate
- Confirm the exact hardware model
- Check Windows Update first
- Read vendor release notes
- Keep a known-working driver available

## "Old" does not always mean "bad"

Stable hardware can use older drivers for years without issues.
AFX Driver Checker highlights older drivers for review only.
